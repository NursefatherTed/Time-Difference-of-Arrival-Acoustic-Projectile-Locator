# Time-Difference-of-Arrival-Acoustic-Projectile-Locator
# Overview
A high-speed acoustic localization system built on the ESP32 framework. This project utilizes a 4-channel MEMS microphone array to instantly calculate the physical bearing of transient acoustic events (such as sharp claps or simulated ballistics) using Time-Difference-of-Arrival (TDOA) geometry.Rather than relying on abstracted Arduino libraries, this system leverages bare-metal C and the ESP-IDF framework to interface directly with the silicon. It continuously streams raw 32-bit audio data into memory via Direct Memory Access (DMA) and processes it using real-time discrete cross-correlation algorithms.

# Core Architecture
Hardware: ESP32 (Dual Core), 4x INMP441 Digital I2S Microphones.Data Ingestion: Exploits both hardware I2S peripherals (I2S0 and I2S1) simultaneously to capture four synchronized streams of audio without external multiplexing.Signal Processing: Implements an amplitude-gated, time-domain cross-correlation matrix to isolate microsecond audio delays between the sensor nodes.Trigonometric Fusion: Converts discrete sample delays into physical time variables, utilizing a four-quadrant arctangent function ($\text{atan2}$) to output a precise 360-degree vector towards the target.RTOS Integration: The heavy acoustic calculus is strictly pinned to Core 1 using FreeRTOS task scheduling, preventing watchdog panics and leaving Core 0 free for future UART/WiFi telemetry.
